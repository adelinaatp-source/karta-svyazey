# Карта связей: процессы и база знаний АРМ

Одностраничная карта, которая сводит два описания одной и той же работы:

- **третья волна описания процессов** — 49 карт, собранных со слов сотрудников;
- **база знаний АРМ** — 847 объектов системы и 105 процессов автоматизации, спроецированных из кода.

Карта показывает, где два описания сходятся, где расходятся и где система умеет то, чего в картах нет.

**Открыть:** https://adelinaatp-source.github.io/karta-svyazey/

## Что внутри

| Вкладка | Что показывает |
|---|---|
| Обзор | Сводные цифры и покрытие объектов АРМ по контурам |
| Процессы | 49 процессов: сколько объектов системы называет каждый и сколько из них подтверждается |
| Объекты АРМ | 153 имени объектов из карт с проверкой по реестру системы |
| Автоматизация | Домены BPMN и десять процессов, не отражённых ни в одной карте |
| Расхождения | Восемь мест, где карта и код говорят разное |
| Границы | Что карта не утверждает и откуда взяты данные |

## Границы

Ни один процесс здесь не утверждён: владелец не назначен ни у одного из 49, статус всех карт — «в работе».
Расхождения не разрешены — выбор канона остаётся за владельцем процесса.
Проекции базы знаний сделаны из кода, а не из данных: они говорят, что система умеет, а не чем пользуются люди.

Персональные данные, тексты интервью и адресаты вопросов в карту не включены.

## Сборка

Страница автономна: один файл `index.html` без внешних зависимостей, данные встроены.
Пересобирается из репозитория описания процессов и проекций базы знаний АРМ.
